# Machine Gun Kelly - Página de Merch

Página de merch do Machine Gun Kelly criada como projeto de estudo, usando HTML, CSS e JavaScript puro (sem frameworks).

🔗 **Ver o site:** (https://github.com/Gibraga/mgk-page/blob/main/site%20mgk.html)

## Funcionalidades

- Menu responsivo, com versão para celular
- Efeito de digitação no subtítulo
- Seções que aparecem suavemente ao rolar a página
- Lista de desejos do merch, salva no navegador (localStorage)
- Formulários com validação (e-mail de ingressos e contato)
- Layout adaptado para computador e celular

## Tecnologias

- HTML5
- CSS3
- JavaScript (ES6)

## Como rodar

Clique e abra o `site mgk.html` no navegador. Não precisa instalar nada.

Projeto sem fins comerciais, feito apenas para estudo. A marca e as imagens pertencem aos seus respectivos donos. Os formulários são demonstrações e não enviam dados.
